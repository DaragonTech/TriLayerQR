| Component | Version | Files | License |
|---|---|---|---|
| [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) by Kazuhiko Arase | 1.4.4 | `vendor/qrcode-generator/` | MIT (`vendor/qrcode-generator/LICENSE`) |
| [jsQR](https://github.com/cozmo/jsQR) by Cosmo Wolfe | 1.4.0 | `vendor/jsqr/` | Apache-2.0 (`vendor/jsqr/LICENSE`) |
| [zxing-wasm](https://github.com/Sec-ant/zxing-wasm) by Ze-Zheng Wu, built on [ZXing-C++](https://github.com/zxing-cpp/zxing-cpp) | 2.2.4 | `vendor/zxing-wasm/` | MIT (`vendor/zxing-wasm/LICENSE`); ZXing-C++ is Apache-2.0 |
| [MediaPipe Face Detection](https://github.com/google-ai-edge/mediapipe) by Google | 0.4.1646425229 | `vendor/mediapipe/face_detection/` | Apache-2.0 |
| [Orbitron](https://fonts.google.com/specimen/Orbitron) by Matt McInerney, via Fontsource | 5.3.0 | `vendor/fonts/orbitron-*` | SIL OFL 1.1 (`vendor/fonts/OFL-Orbitron.txt`) |
| [Rajdhani](https://fonts.google.com/specimen/Rajdhani) by Indian Type Foundry, via Fontsource | 5.3.0 | `vendor/fonts/rajdhani-*` | SIL OFL 1.1 (`vendor/fonts/OFL-Rajdhani.txt`) |
